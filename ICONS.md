# Crazy Tuk Icons

## Required Icons

### For PWA Installation

1. **crazytuk-192.png** (192x192px) - App icon for home screen
2. **crazytuk-512.png** (512x512px) - App icon for device lists
3. **crazytuk-touch-icon.png** (180x180px) - Apple touch icon

### For Social Media

4. **crazytuk-social-card.png** - Open Graph and Twitter share image

### Location

These should be placed in the root `/` directory (not inside `assets/`)

## Temporary Placeholders

Until icons are created, you can use:
- `bunkee.ico` (renamed to `crazytuk.ico`)
- Copy `apple-touch-icon.png` to `crazytuk-touch-icon.png`
- Use any placeholder image for social card

## Notes

- Icons should match Crazy Tuk branding (red/cyan color scheme)
- Use PNG format with transparency support where needed
- Follow standard icon guidelines for clarity and visual hierarchy
